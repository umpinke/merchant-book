# Merchant Book

Fabric mod for Minecraft 26.3. Adds a Merchant Book (book + emerald). Right click it and you can look up which trades every villager profession and the wandering trader can have on each level.

## Requirements

- Minecraft 26.3
- Fabric Loader 0.19.5 or newer
- Fabric API
- Has to be installed on the server too (singleplayer is fine)

## Building

`./gradlew build`, the jar is in `build/libs`.

`./gradlew runClientGameTest` runs an ingame test and saves some screenshots.
